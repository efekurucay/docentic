docentic

An agentic assistant that answers from your static site's content. Self-hosted, one script tag, open source.

Knows your siteIt reads your pages with tools — search, open, follow — and answers only from what it finds.
Your server, your keyRuns on your machine via one Docker command. Your model key never reaches the browser.
One tag to embedNo framework, no build. Drop a <script> into any static site.
Isolated & privateEach visitor gets their own session. One conversation never leaks into another.

How it works

docentic discovers your pages from sitemap.xml (or a one-level link crawl), stores clean page text in SQLite with full-text search, and gives the model three read-only tools. The loop runs until the model stops calling tools, streaming the answer over SSE.

visitor → widget.js → POST /chat (SSE) → docentic → OpenRouter
                                            │ tools: list_pages · read_page · search
                                            ▼
                                      SQLite (pages + FTS5, sessions, messages)
                                            ▲ sitemap.xml + fetch
                                      your static site

Run it

docker run -p 8080:8080 \
  -e OPENROUTER_API_KEY=sk-or-... \
  -e MODEL=openrouter/free \
  -e ALLOWED_ORIGINS=yoursite.com \
  ghcr.io/efekurucay/docentic

Embed it

<script src="https://your-docentic-host/widget.js"
        data-endpoint="https://your-docentic-host"
        data-key="your-site"
        data-title="Ask this site"></script>

Configuration

Env varDefaultMeaning
OPENROUTER_API_KEY—Your OpenRouter key (required). Never sent to the browser.
MODELopenrouter/freePrimary model; routes over free models.
FALLBACK_MODELdeepseek/deepseek-v4-flashUsed if the primary call fails.
ALLOWED_ORIGINS—Hostnames allowed to embed and be crawled.
MAX_TURNS8Max agent iterations per question.
RATE_LIMIT_PER_MIN20Requests per minute per IP.

Security

SSRF-safe (only ALLOWED_ORIGINS are fetched), read-only parameterized SQL, origin allowlist + honeypot + rate limit, and prompt-injection handling — page text is data, not instructions. Sessions are isolated by design.
